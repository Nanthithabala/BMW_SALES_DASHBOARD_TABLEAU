# BMW Sales Dashboard - Tableau

## Project Overview

This Tableau dashboard provides a comprehensive analysis of BMW sales performance. The dashboard helps track revenue, profit, customer satisfaction, sales trends, and target achievement while uncovering insights into vehicle model performance and fuel-type preferences through interactive visualizations.

## Key Features

* Revenue Performance Analysis
* Profit Analysis
* Customer Satisfaction Tracking
* Model Performance Insights
* Fuel-Type Preference Analysis
* Monthly Sales Trend Analysis
* Target vs Actual Comparison
* KPI Cards
* Interactive Filters and Slicers

## Key Metrics

* Total Revenue: 19.23M+
* Total Profit: 4.91M+
* Total Orders: 1K+
* Customer Satisfaction: 4.18/5
* Revenue Target Achievement: 96.15%
